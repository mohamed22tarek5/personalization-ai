## 1️⃣ Extension: ChatGPT to Word / PDF

حوّل أي إجابة إلى مستند Word / PDF منسق، بمعادلات تظهر بشكل صحيح مثل الكتب العلمية.

### Install | التثبيت

1. افتح الرابط الرسمي (نفس الرابط المحفوظ في `importantlinks.md`):

   👉 **[ChatGPT to Word or PDF — Chrome Web Store](https://chromewebstore.google.com/detail/chatgpt-to-word-or-pdf/mjdmggegbkookpcmbdllcnbfboikcbop)**

2. اضغط `Add to Chrome` → `Add extension`
3. افتح أي محادثة ChatGPT → ستجد زر التصدير الجديد
4. اضغطه لتنزيل الإجابة كـ Word / PDF

### 🔄 Renewal Note | ملاحظة التجديد

> بعد انتهاء الحصة التجريبية: افتح صفحة الإضافة ← `Remove from Chrome` ← أضفها من جديد بنفس الرابط أعلاه.

## 2️⃣ Custom Instructions Setup

يرفع مستوى الإجابات إلى معايير Pro: دقة، مصادر أصلية، صياغة منظمة، كود جاهز للإنتاج.

| Step | Action |
|---|---|
| 1 | افتح ChatGPT ← `Settings` ← `Personalization` |
| 2 | افتح ملف `CHATGPT_MORE_SETTINGS.md` من هذا المستودع |
| 3 | انسخ القسم بعنوان `Custom instructions` |
| 4 | الصقه في حقل **Custom Instructions** ← احفظ `Save` |

**What it does:** يلزم النموذج بالتحقق قبل الإجابة، الاستشهاد بمصادر موثوقة (Nature، Science، IEEE، PubMed...)، وعدم التخمين أبدًا — أو قول `I cannot confirm this` عند عدم التأكد.

## 3️⃣ More About You Setup

يخصص الأسلوب والعمق حسب خلفيتك المهنية.

| Step | Action |
|---|---|
| 1 | افتح `Settings` ← `Personalization` |
| 2 | اكتب اسمك ومجال عملك / دراستك |
| 3 | من `CHATGPT_MORE_SETTINGS.md` انسخ قسم `More about you` |
| 4 | الصقه في الحقل المخصص ← احفظ |

**Result | النتيجة:** ردود بمستوى خبير، بلغة مباشرة، مع جداول وخطوات وأمثلة عملية — بدل الإجابات العامة.

## 4️⃣ AI Booster Message

رسالة جاهزة تُضبط بها سلوك **أي** أداة ذكاء اصطناعي (ChatGPT، Claude، Gemini، Copilot...).

### Usage | الاستخدام

1. افتح محادثة جديدة
2. افتح ملف `Personalization chat gpt.md`
3. انسخ النص تحت عنوان **`Send This Message`**
4. أرسله للأداة (كرره 2-3 مرات في البداية لأفضل تثبيت)
5. 🔁 أعِد إرساله كل **أسبوع–أسبوعين** لتنشيط السياق والحفاظ على القمة

## 🎨 Image Prompt Engineering

لا تطلب توليد صورة مباشرة — حوّل طلبك إلى Prompt هندسي احترافي باستخدام ملف `Image_Prompt_Engineering_Rules.md` (يغطي: التكوين، الإضاءة، الألوان، الكاميرا، النصوص، الـ Negative Prompt).

**القاعدة الذهبية:** انسخ طلبك + القواعد → الصقه في أداة الصور الخارجية (Midjourney / DALL·E / Stable Diffusion).

## 💡 Pro Tips | نصائح احترافية

- ✅ ثبّت الإعدادات على حساب واحد للحفاظ على اتساق السياق.
- ✅ للبرمجة: اطلب دائمًا المدخلات / المخرجات + معالجة الأخطاء + متطلبات التشغيل.
- ✅ للمعلومات الحديثة (أسعار / قوانين / إصدارات): اطلب التحقق من الموقع الرسمي أولًا.
- ✅ للأبحاث: اطلب نوع الدراسة + حجم العينة + القيود + المصدر الأصلي.
- ❌ لا تطلب معلومات حساسة أو تشخيصًا طبيًا نهائيًا من AI.
